# Advanced Interactive Dashboard

This project is a **dynamic and interactive personal dashboard** built using **HTML, CSS, and JavaScript**.

### Features:
- Real-time **clock**
- Live **weather information** using OpenWeatherMap API
- **To-do list** with **local storage**
- **Portfolio cards** with hover effects
- **Dark/Light mode toggle**
- Responsive design with animated styling

### How to Use:
1. Clone this repo.
2. Open `index.html` in your browser.
3. Add your OpenWeatherMap API key in `script.js`.
4. Start interacting with the dashboard!

### Skills Showcased:
- Front-end development
- API integration
- DOM manipulation
- Local storage management
- CSS animations and transitions
